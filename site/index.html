What’s inside

🎙️ Voice in

Send a voice note. It’s transcribed locally with whisper.cpp and runs like typed text.

👀 Live progress

One message, live-edited as Claude thinks and calls tools. Every subagent gets its own.

🚫 Cancel anytime

Every run carries a Cancel button. Tap it and the process stops immediately.

🔊 Voice out

Replies as natural-sounding voice notes, with prosody tags for less robotic speech.

Works from anywhere you can type

Parallel projects

One bot per working directory, each with its own persistent session. Check each for thirty seconds.

Background jobs

Long tasks survive the turn, a timeout and even a bridge restart, with a live status message.

Groups & topics

Use it in group chats and forum topics, with mention-only mode and per-topic sessions.

Safe by default

Allow-listed user IDs only, plus a CONFIRM gate for risky commands like rm -rf.

Rich formatting

Real Telegram formatting: code blocks, links, quotes and aligned tables.

Zero dependencies

Plain Node 20+. No npm install. Just a config file and a bot token.

Up and running in a minute

  1. Create a bot with @BotFather and copy the token.
  2. Clone and configure 
    git clone https://github.com/suhocki/telegram-claude-bridge.git
cd telegram-claude-bridge
cp tldr.config.example.json my-bot.config.json
  3. Run it 
    node bridge.mjs my-bot.config.json

Want it to survive reboots? Generate a launchd agent with scripts/gen-launchagent.mjs.

Why Telegram?

Because it already solved the hard parts — voice notes, push notifications, file transfer, multi-device sync, offline queuing — for free. The bridge just plugs Claude Code into all of that.

FAQ

Does it need claude --channels?

No. It polls the Bot API directly and shells out to claude -p --resume, so it works even where channels are blocked by org policy.

Where does my data go?

Chat content transits Telegram’s servers as a third-party relay. Keep it to personal, non-sensitive projects.

Which platforms?

The bridge is cross-platform Node. The auto-start setup uses macOS launchd.

Is it free?

The bridge is open source. You bring your own Claude subscription or API key.
